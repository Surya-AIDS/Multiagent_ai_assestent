EXECUTIVE SUMMARY

Mission & Core Objective

🎯

Core Objective

To empower creators, companies, legal teams, and researchers with evidence-based, explainable copyright similarity detection and risk scoring without replacing professional legal counsel.

  • Factual similarity detection across multi-modal assets
  • Quantifiable risk scoring & confidence metrics
  • Transparent evidence tables & passage diffs
⚖️

Ethical & Non-Legal Authority Stance

The system operates strictly as an evidence gathering and investigation assistant. It provides objective factual findings rather than binding legal conclusions.

  • Distinguishes verified facts from AI observations
  • Applies statutory frameworks (17 U.S.C. § 107 Fair Use)
  • Encourages professional attorney review

TECHNOLOGY

Core Detection Algorithms

📖 Text Paraphrase Detection

Combines Cosine similarity over word frequency vectors with sentence-level sliding windows to detect reworded or paraphrased paragraphs.

💻 AST Code Clone Analyzer

Analyzes code AST tokens, loop depth, and variable renaming patterns to catch code clones even when variables and comments are altered.

📚 Vector DB & Perceptual Hashing

In-memory vector database for real-time top-K retrieval and canvas pixel feature extraction for visual asset similarity verification.

RISK ASSESSMENT

5-Tier Infringement Risk Matrix

Risk Classification Levels

  • Very Low (0-20%): Original creation, common domain knowledge
  • Low (21-40%): Standard quotes with proper citation
  • Medium (41-60%): Missing citation or uncredited quote
  • High (61-80%): Heavy paraphrasing or uncredited copyleft code
  • Critical (81-100%): Verbatim wholesale duplication

Evaluation Factors

The Risk Assessment Agent evaluates both quantitative density (word match percentage) and qualitative legal impact (Fair Use 4-Factor Test, market substitution, and license copyleft conditions).
